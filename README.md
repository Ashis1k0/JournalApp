## My Journal App 📝
This is a Spring Boot application designed to function as a simple journal app. It provides a RESTful API for creating, reading, updating, and deleting journal entries.

## Features ✨
Create Entry: Users can create new journal entries.

View Entries: Users can retrieve a list of all their journal entries.

View Single Entry: Users can view a specific journal entry by its ID.

Update Entry: Users can modify an existing journal entry.

Delete Entry: Users can delete a specific journal entry.

In-Memory Database: The application uses an H2 in-memory database, which is ideal for quick startup and development.

## Technologies Used 💻
Java 17: The core programming language.

Spring Boot 3.2.1: The framework for building the application.

Spring Web: Provides RESTful API functionality.

Spring Data JPA: Used for database interaction and persistence.

H2 Database: A lightweight, in-memory database used for development.
